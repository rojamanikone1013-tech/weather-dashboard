# Weather Dashboard

A modern and responsive Weather Dashboard built using HTML, CSS, JavaScript, and OpenWeatherMap API. The application provides real-time weather information, hourly forecasts, and 5-day weather predictions for any city worldwide.

## Features

- Search weather by city name
- Current location weather using Geolocation API
- Real-time temperature updates
- Hourly weather forecast
- 5-Day weather forecast
- Weather details:
  - Temperature
  - Humidity
  - Wind Speed
  - Pressure
  - Visibility
  - Sunrise & Sunset
- Weather icons
- Dark/Light Theme Toggle
- Responsive Design
- Local Storage Theme Persistence

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Tailwind CSS
- OpenWeatherMap API
- Geolocation API

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/rojamanikone1013-tech/weather-dashboard.git
```

2. Open the project folder:

```bash
cd weather-dashboard
```

3. Open `index.html` in your browser.

## API Setup

1. Create an account at OpenWeatherMap.
2. Generate an API key.
3. Replace:

```javascript
const APIKEY = "YOUR_OPENWEATHER_API_KEY";
```

with your actual API key.
